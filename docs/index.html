What this repository does

The compatibility layer
between Dell hardware and macOS.

The repository is not an installer and does not contain macOS. It provides the EFI files OpenCore needs to initialize the hardware, patch macOS where necessary and boot the operating system.

Graphics

Intel HD Graphics 630

Configured through WhateverGreen and Lilu with Intel framebuffer properties, HDMI 2.0 support and connector patches.

Native-style audio

Getting started

From repository to boot menu.

Use the EFI as a hardware-specific starting point. Keep a backup of any known-working EFI before making changes.

git clone https://github.com/Epikaigle/Hackintosh_Dell_Optiplex_3050.git
  1. 1
    Create your macOS installer

    Obtain macOS from Apple and prepare a bootable installer or recovery environment.

  2. 2
    Mount the EFI partition

    Mount the EFI partition on the installer USB or target system drive.

  3. 3
    Copy this repository's EFI

    Place the EFI folder at the root of the EFI partition.

  4. 4
    Generate your own SMBIOS

    Replace SystemSerialNumber, MLB, SystemUUID and ROM before using Apple services.

  5. 5
    Boot through OpenCore

    Select the OpenCore UEFI entry from the Dell boot menu and start macOS.

!
Important before you use it

Never reuse public SMBIOS identifiers.

The public config.plist contains PlatformInfo values. Treat them as placeholders. Generate unique identifiers for your own installation before signing into iCloud, iMessage, FaceTime or other Apple services.
