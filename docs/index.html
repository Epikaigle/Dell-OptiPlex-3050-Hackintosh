An OpenCore EFI configuration for running macOS Sequoia on a compatible Dell OptiPlex 3050. This page explains what the repository contains, how it works, and how to use it.

Overview

What this repository is for.

The repository contains the EFI boot environment used by OpenCore. It does not contain macOS and it is not a macOS installer.

OpenCore starts before macOS. It provides the ACPI patches, UEFI drivers, kernel extensions and device properties needed for macOS to recognize the OptiPlex hardware correctly.

The current configuration uses an iMac19,1 SMBIOS and is set up around Intel HD Graphics 630, onboard audio, Realtek Ethernet, USB and Dell hardware sensors.

Installation

How to use the EFI.

The EFI is intended as a starting point for a compatible OptiPlex 3050. Keep a backup of a known-working EFI before changing your installation.

  1. 1

    Create the macOS installer

    Obtain macOS from Apple and create your installer or recovery media separately.

  2. 2

    Mount the EFI partition

    Mount the EFI partition of the USB installer or the target system disk.

  3. 3

    Copy the EFI folder

    Place the repository's EFI folder at the root of the EFI partition.

  4. 4

    Generate your own SMBIOS identifiers

    Keep the iMac19,1 model, but generate unique values for SystemSerialNumber, MLB, SystemUUID and ROM.

  5. 5

    Check the BIOS configuration

    Use UEFI boot and settings appropriate for OpenCore/macOS, including AHCI for SATA. Verify your own firmware configuration before changing options.

  6. 6

    Boot OpenCore

    Select the OpenCore entry from the Dell boot menu, then start the macOS installer or system.

Lilu

Base patching framework used by several other Hackintosh extensions.

WhateverGreen

Intel graphics initialization and framebuffer/display patching.

AppleALC

Audio support through Apple's native audio framework.

VirtualSMC

Provides the System Management Controller layer expected by macOS.

RealtekRTL8111

Support for the onboard Realtek Ethernet controller.

Sensor plugins

CPU, Super I/O and Dell-specific hardware monitoring.

Important

Use your own SMBIOS data.

The public config.plist contains PlatformInfo values. Do not use public identifiers as permanent identifiers for your own machine. Generate unique values before signing in to iCloud, iMessage, FaceTime or other Apple services.
